## 口径提醒（避免与主文档矛盾）

- 项目**最终未迁移图数据库**（Neo4j 等），保持单一 SQLite。第一阶段文档 §3 中「第二阶段迁 Neo4j」属**当时的规划**，最终未采用 —— 以《项目设计文档》§0.3 的实测结论为准。
- 项目定位为**图谱增强的 RAG**（Knowledge-Graph-Enhanced RAG），**不含**社区检测与社区摘要，详见《项目设计文档》§0.4。
- 测试口径演进：**64 通过 + 1 跳过** →（AT-09 Embedding 降级 +2）**65 项** →（权限边界 +2）**67 项（66 通过 + 1 跳过）** →（用户自带密钥 +10）**77 项（76 通过 + 1 跳过）** →（部署形态与额度 +18）**95 项（94 通过 + 1 跳过）** →（检索、时效、公开演示与索引回归 +10）**105 项（104 通过 + 1 跳过）** →（身份分档与模型接入 +13）**118 项（117 通过 + 1 跳过）**。
- 部署形态：默认 **public**（不采集用户密钥、默认原文摘编）；自部署 / 自用设 `SCHOOL_DEPLOY_MODE=selfhost`。第四阶段文档描述的 BYOK 行为属于 **selfhost 形态**；第六阶段之后的默认路径是「聊天窗口选模型，密钥存浏览器」，BYOK 接口保留但不再是主路径。
- 身份策略：学生可自助注册；**老师与管理员只能由管理员导入名单**。空库首个账号免鉴权（bootstrap），这是初始化必需，不是漏洞。
