## 2. 本地模型接入

`local_models/models/` 下有两个 HuggingFace 快照目录：

| 模型 | 用途 | 维度 |
| --- | --- | --- |
| BAAI--bge-small-zh-v1.5 | 中文 Embedding（替换哈希向量器） | 512 |
| BAAI--bge-reranker-base | 重排序（CrossEncoder，RRF 融合后二次排序） | — |

**接入设计**（`app/ml_local.py`）：
- 惰性加载 + 进程内单例 + 线程锁；首次调用才加载，失败自动降级。
- `_resolve_model_dir`：自动定位 `snapshots/master/` 快照子目录（模型文件实际所在处）。
- 开关：`USE_LOCAL_EMBEDDING` / `USE_LOCAL_RERANKER` ∈ {auto, on, off}；`ML_DEVICE` 选 cpu/cuda。

**Embedding 优先级**：本地 BGE → Embedding API → 哈希向量器（三级降级，§7.2）。
**维度一致性**（`app/retrieval/vector.py`）：向量表维度与当前 embedder 不一致时自动清空重建，避免切换模型后余弦相似度恒为 0。

**实测**：
- BGE Embedding：512 维，首次加载约 18s；
- Reranker：对"缓考怎么申请"，正确把"缓考相关"句子排第一（0.94）vs 无关句子（0.015）。

## 3. 质量评测（F16）

评测集 `data/evaluation.json`（**55 题**），每题标注 `relevant_docs`（相关文档）与 `keywords`（事实线索）。

指标（离线可复现，不依赖外部判分）：
- **Recall@K**：Top-K 检索去重后命中相关文档的比例；
- **事实一致性**：检索内容命中关键词线索的比例；
- **引用覆盖率**：有引用回答的占比。

**实测报告**（Top-K=5，**55 题**）：Recall@5 = **0.90**，事实一致性 0.70，引用覆盖率 1.0。

## 4. 增量入库与 SUPERSEDES（F17）

`app/service/ingestion.py`：
1. 老师/管理员上传通知文本（`POST /ingest/notice`）；
2. 按段落解析 → 写入 documents/clauses（INSERT OR REPLACE 幂等）；
3. **SUPERSEDES 检测**：同类别 + 标题去数字/标点后相同或互为子串 → 视为新版替代旧版；
4. 自动写入 `SUPERSEDES` 关系，旧文档 status 置「已被替代」；
5. 增量构建向量。

> 风险应对（§8）：检测为"建议 + 自动执行"，如需更保守可设 `auto_supersede=false` 改为人工审核。

**实测**：上传《2026 年奖学金评定通知》→ 自动替代 2024 与 2025 通知。

## 5. 多用户隔离与权限（F15）

- `users` 表：user_id / username / role / api_token；角色 student / teacher / admin。
- 鉴权：请求头 `X-User-Token`；未提供 → 匿名（只能看自己 data，无权限）。
- 隔离：sessions / messages / mastery / quiz_attempts 均带 user_id；匿名与登录用户数据互不可见。
- 权限：老师/管理员可增量入库与跑评测；管理员可查看用户列表。

## 6. 引用全量展开（F14）

- 来源条款：`citations` 含 doc_id / chapter / article_no / snippet；

- 关系路径：`GET /graph/paths/{node_id}` 返回实体到部门/流程的关系路径（`app/service/paths.py`）。

## 7. 容器化与备份（F18）

- `Dockerfile`：python:3.12-slim 构建后端；启动时先幂等导入再起服务。
- `docker-compose.yml`：`backend`（8000）+ `frontend`（nginx 托管 SPA，8080，反向代理 /api）；本地模型与数据用命名卷挂载。
- `deploy/nginx.conf`：前端静态 + /api 反代 + /docs。
- `app/backup.py`：SQLite `backup` API 在线一致性备份 + restore。

## 9. 已知限制

- Reranker 每次 `predict` 有毫秒~秒级开销，高并发下需批处理（已在 QA 单查询路径应用）。
- 会话/用户持久化仍为 SQLite，高并发生产环境建议迁移 PostgreSQL（§6#15 完整版）。
- 本地模型未随代码提交（`local_models/` 已 gitignore），部署需挂载卷或单独分发模型文件。
